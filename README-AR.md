# تطبيق مستودع المعري

## أولاً: إعداد Supabase (مرة واحدة)
1. أنشئ مشروعاً مجانياً على supabase.com.
2. من SQL Editor افتح الملف supabase-setup.sql، وغيّر OWNER_EMAIL_HERE إلى بريدك أنت (المالك)، ثم شغّله.
3. من Authentication ثم Users اضغط Add user، واكتب بريدك نفسه وكلمة مرور، وفعّل Auto Confirm User.
4. من Authentication ثم Sign In / Providers أوقف خيار السماح بتسجيل مستخدمين جدد (Allow new users to sign up).
5. من Project Settings ثم API انسخ Project URL وanon public key، وضعهما في الملف www/config.js.

## ثانياً: بناء الـ APK على GitHub (بدون برامج)
1. أنشئ مستودعاً على github.com وارفع محتويات هذا المجلد (www وassets وpackage.json وcapacitor.config.json).
2. المجلد المخفي .github قد لا يرتفع. إن لم يظهر: Add file ثم Create new file واكتب الاسم
   .github/workflows/build-apk.yml والصق محتوى الملف build-apk.yml المرفق.
3. من تبويب Actions شغّل Build APK وانتظر نحو ١٠ دقائق.
4. نزّل app-debug.apk من Artifacts وثبّته على الجوال.

## ثالثاً: أول استخدام
1. افتح التطبيق، اضغط ⚙ ثم سجّل دخولك ببريدك وكلمة المرور.
2. اضغط «رفع الكتالوج الحالي إلى السحابة» مرة واحدة وانتظر انتهاء الرفع.
3. من لوحة التحكم أضف المندوبين (الاسم والرقم)، ثم تحكم بالشركات والمنتجات والعروض.
   كل تعديل يظهر مباشرة على كل الأجهزة.

## ملاحظات
- الطلب عبر واتساب يرسل اسم المنتج والعدد ورابط الصورة (يظهر كمعاينة). واتساب لا يسمح بإرفاق الصورة نفسها عبر الرابط.
- العرض له بداية ونهاية واختيار انفجار تلقائي عند البدء، وزر «إطلاق 💥» لإطلاقه يدوياً في أي وقت.
- هذه نسخة debug للتجربة والتوزيع المباشر. للنشر على Google Play نحتاج نسخة موقّعة وحساب مطوّر.
